# Surface brief — kaskadyor.uz hero (single page)

Scope: the entire site — one page, one semantic hero section. Mode: Persuade.
Audience/job: riders in Uzbekistan, mostly on phones from Instagram/Telegram, deciding in seconds whether Kaskadyor is a serious moto shop. Action: open the Telegram shop group (catalog) or Instagram (contact).
Proof/content: client copy, Codex asset package (motorcycle, environments, helmet/gloves/suit). No invented claims.
Constraints: brief-pinned palette, copy, structure (see PRODUCT.md). Code-led build (no image generation in this harness).

## Direction contract

THESIS: A night-garage campaign one-sheet where the gear indicator is the navigation — the bike stands in a single pool of light, and shifting N→1→2→3 racks focus from machine to equipment. Refuses the category default of a split hero with a product-card grid below.

OWN-WORLD: Obsidian #08090C ground, wet asphalt floor, one red rim light. Barlow Condensed 800 set huge and tight; Manrope body. Hairline 1px rules in silver at low alpha, square corners, red used only for the active gear, the primary action, one headline line and the strip's single micro-accent. Carbon weave as the faint background layer behind the copy (brief-pinned layer 4), nowhere else.

STORY: Visitor feels the machine first, reads TEZLIKNI / HIS QIL. / HIMOYANI TANLA., shifts through gears to see that Kaskadyor kits the rider, then taps into Telegram.

FIRST VIEWPORT (1440×900): nav 0–84; left 42% column — client lead-in set as the headline's first beat (display face, 0.36×H1, silver), three-line H1 (~6rem), description, red primary + outline secondary; bike subject ~52vw on the right, wheels on the floor line at ~86%; gear plate top-right above the tail; info strip with socials at the bottom edge.

FORM: brief-pinned "Obsidian Motorsport / Redline Edition"; signature interaction = gear-shift focus pull. concept-seed not run (direction pinned by client brief, 2026-10-12).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
